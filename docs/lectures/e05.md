# E05 复利资产

> 本讲关键词：一次生产 · 多次收款 · 资产清单

复利资产是 OPC 和自由职业的分界线。自由职业卖当天的精力；OPC 卖过去已经做完、今天还能继续收款的东西。

对 AI 产品经理，最容易被忽略的资产不是代码，而是：**被验证过的问题定义、提示词、评审口径、案例和名单。** 这些东西你已经有了，只是还散落在聊天记录里，没有被产品化。

## 什么能复利，什么不能

能复利的，必须同时满足：

1. **可保存**：离开你的大脑，别人还能用
2. **可重复**：同一类买家会反复遇到
3. **可升级**：v1 能卖，v2 还能卖给同一批人
4. **可分发**：不依赖你实时在场

不能复利的，往往很像工作：回复私信、开会、按客户要求改一版、陪聊。这些可以养现金流，但要把其中重复的 20%，抽出来做成资产。

## 一人公司的资产分层

从近到远，建议按这个顺序堆：

1. **名单资产**：真正付过钱或认真咨询过的人
2. **内容资产**：把同一个观点做成文章、音频、清单
3. **方法资产**：可交付的模板、SOP、评分表
4. **产品资产**：能自动或半自动成交的信息产品 / 工具
5. **品牌资产**：别人用一句话转述你是谁

很多人倒着做，先追求品牌，再做产品。OPC 要正着做：先有名单和方法，品牌是副产品。

## 每周只做一件资产动作

不要同时开十个专栏。给自己一个固定节奏：

- 周一：把本周重复被问到的问题记下来
- 周三：把其中 1 个做成可转发的内容
- 周五：把其中可交付的部分收成模板，挂到产品里

三个月后，你手里会有 12 个模板和一批名单。这比 12 个“新想法”值钱得多。

## 本讲作业

列一张资产清单，只写已经存在的，不写计划：

- 我有多少个付费/深度咨询过的联系人
- 我有多少份可直接发给客户的模板
- 我有多少条可以反复使用的内容
- 这些东西上周帮我收了多少钱

如果最后一格是 0，从本周起，任何交付都先问一句：这件事做完，能不能留下一份别人还能用的版本？
