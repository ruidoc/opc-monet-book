# E14 选品思维

> 本讲关键词：谁会买 · 你能否交付 · 能否重复卖

选品不是选一个热门赛道，是选一个**你能反复卖、反复交付、反复积累资产**的交易结构。赛道热，只说明竞争者多；交易结构对，才说明一人公司能活。

AI 产品经理选品时有两个偏见：一是高估自己能做多复杂的产品，二是低估“不够酷”的产品有多好卖。清单可能比 Agent 好卖，诊断可能比平台好卖。酷不是验收标准，重复成交才是。

## 选品的四个过滤器

按顺序过，不要跳：

1. **需求是否带损失**：不买会怎样？只是错过鸡汤，还是会掉钱、掉时间、掉机会
2. **你是否有证据**：做过、帮过、踩过，而不是“我觉得有市场”
3. **交付是否单人可完成**：一周 10 小时内能否服务下一批客户
4. **卖完能否留下资产**：模板、案例、名单会不会变多

四个里失败任意一项，就换品。不要用“先做起来再说”跳过第 3 项，那会把你做回外包。

## 好人品长什么样

早期更可能赢的品，通常长这样：

- 买家预算来源清楚（报销、求职、上线窗口、副业第一单）
- 决策链短，一个人就能付钱
- 结果可在 7–30 天被看见
- 你已经用非产品形态帮人解决过至少 3 次

如果一次都没帮人解决过，先用服务验证，不要直接做标准品。选品是验证的结果，不是灵感的结果。

## 不选什么

- 需要大量客服才能维持评价的品
- 依赖平台算法、自己完全不可控的品
- 你必须 24 小时在线才能交付的品
- 你看不上、但假装能热爱五年的品

一人公司的库存是你的注意力。选错品，后面所有讲的飞轮都会空转。

## 本讲作业

准备 3 个候选品，分别用四个过滤器打分（0–2 分）。只保留总分最高且没有 0 分项的那一个。

把另外两个放进“以后也许”清单。OPC 的纪律是：同时只主推一个品。
