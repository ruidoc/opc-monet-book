# E10 转化漏斗

> 本讲关键词：看见 · 兴趣 · 信任 · 付款 · 流失点

漏斗不是大公司的报表游戏。一人公司更需要漏斗，因为你没有销售团队帮你补洞。漏斗的价值是：**让你知道该修哪一层，而不是感觉“最近不太行”然后更拼命发内容。**

产品经理对漏斗不陌生。差别在于，OPC 的漏斗更短，每一层都要能被你亲手数出来。

## 五层就够

1. **曝光**：多少人看到
2. **停留**：多少人看完 / 点开
3. **行动**：多少人加你、填表、回复
4. **成交**：多少人付钱
5. **复购**：多少人第二次付钱

前两层看内容，中间一层看入口，后两层看产品和交付。很多人只盯第一层，用播放量安慰自己，漏斗其实在第三层就断了。

## 怎么找洞

连续记录 14 天，不要凭感觉：

- 每天曝光
- 每天新进私域人数
- 每天有效对话（对方说了具体需求）
- 每天报价次数
- 每天成交次数

然后看断在哪：

- 曝光高、进入低：入口太绕，或好处不清楚
- 进入高、对话低：欢迎语在自说自话，没有提问
- 对话高、报价低：你在免费咨询，没有把对话推向产品
- 报价高、成交低：价格结构或信任材料不够
- 成交有、复购无：结果不稳，或没有下一档产品

## 一人公司的转化原则

- **每一层只优化一个变量。** 同时改文案、改价格、改产品，你不知道是什么起作用。
- **对话比资料更接近成交。** 但对话必须有剧本：问场景、问损失、给选项。
- **不要用新内容掩盖旧漏洞。** 洞不补，发得越多，浪费越大。

## 本讲作业

按上面五层，把上周的真实数字填进去。哪一层转化率最低，就只修那一层 7 天。

修的时候写清：我改了什么、我期望哪一个数字动、7 天后实际动了没有。这就是一人公司的增长实验。
