# E03 知识套利

> 本讲关键词：认知差 · 场景差 · 时间差

知识套利不是贩卖焦虑，也不是把公开信息重新排版。它的本质是：**你比买家更早、更结构、更可执行地知道一件事，并把这件事变成对方愿意付钱的结果。**

AI 产品经理身处信息密度最高的岗位之一。你每天看模型更新、看竞品、看评审、看失败项目。这些对你是日常，对买家可能是三个月的试错成本。套利，就是把你的“日常”标成别人的“捷径”。

## 三种差价

- **认知差**：你已经验证过，对方还在猜。例如“这个场景不该上 Agent，该上工作流”。
- **场景差**：同样的方法，换一个垂直行业就值完全不同的钱。通用提示词便宜，医疗质检提示词贵。
- **时间差**：你提前 30 天踩过坑，对方现在就要上线。时间越紧，套利空间越大。

一人公司不要追求“我知道全世界不知道的秘密”。秘密很难规模化。可规模化的是：**把已知方法，做成某个具体岗位今天就能用的版本。**

## 怎么找你的差价

把你过去 12 个月做过的事摊开，圈三类：

1. 你做过超过 3 次、别人还在问“怎么开始”的
2. 你能在 60 分钟内讲清楚，对方听完能立刻行动的
3. 对方不行动，会直接掉钱、掉Offer、掉上线窗口的

三类交集，就是你的知识套利带。注意第 3 条：没有损失压力的知识，通常只能换点赞，换不来付款。

## 套利的产品形态

从轻到重，常见四档：

1. **清单 / 核对表**：把隐性经验显式化
2. **拆解 / 案例包**：把一次成功路径复制给同类人
3. **工作坊 / 诊断**：帮对方定位，而不是帮对方执行全部
4. **陪跑 / 代做**：差价最大，也最吃时间，必须限量

第一稿先做 1 和 2。它们是后面复利资产的原材料。3 和 4 用来验证价格，不要一上来就把自己卖成全职外包。

## 本讲作业

写出 3 个“只有你能快速交付”的知识差，每个用一句话：

> 我比【谁】更早知道【什么】，对方现在做【某事】会因此少付【时间 / 金钱 / 风险】。

选其中损失最大的一条，作为你下周的内容选题和 MMP 卖点。
