# E07 一千个铁粉

> 本讲关键词：深度关系 · 1000人 · 足够赚钱

一千个铁粉不是口号，是经营单位。铁粉的定义很硬：**他们信任你的判断，愿意反复付钱，也会把你转介绍给同类人。** 粉丝是观看关系，铁粉是交易关系。

对一人公司，1000 是一个刚好够用的数：少了，收入不稳；多了，你开始需要团队和流程来维持温度。先把 1000 做透，再谈百万播放。

## 铁粉从哪里来

不是从爆款来，是从三次重复接触来：

1. 第一次：被一个具体观点击中
2. 第二次：发现你持续在同一条线上说话
3. 第三次：买过一次，结果对得上预期

三次里任何一次漂了——今天讲 AI，明天讲情感，后天讲投资——铁粉就不会形成。OPC 要忍受重复。重复对观众是确认，对创作者是无聊，无聊往往是正确的信号。

## 1000 人怎么养

把 1000 拆成可执行的阶段：

| 阶段 | 人数 | 你该做的事 |
| --- | --- | --- |
| 种子 | 0–50 | 全部手动聊，记录他们的原话 |
| 村 | 50–200 | 开始固定节奏，形成“你是谁” |
| 镇 | 200–500 | 产品标准化，减少一对一解释 |
| 城 | 500–1000 | 分层：大众内容 + 少量深度服务 |

在 50 人之前就做自动化，通常是在逃避和真人说话。50 人的原话，会直接决定你后面的选题、定价和选品。

## 铁粉的三个行为

识别铁粉，不要用点赞，要用行为：

- 会主动把问题抛给你
- 会在你涨价后仍然留下
- 会在别人质疑时替你解释

这三类人值得被单独记住。他们是你的渠道、你的产品经理、你的质检。一人公司没有用户研究团队，铁粉就是研究团队。

## 本讲作业

建立铁粉名单，先不求 1000，先求 20：

- 姓名 / 来源
- 他因为哪句话找到你
- 已经买过什么
- 下一步最可能买什么

每周只认真维护这 20 人。1000 是结果，20 是开始。
